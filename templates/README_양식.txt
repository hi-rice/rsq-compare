[양식·예시 파일 설명]
※ 아래 파일 안의 숫자는 모두 '예시(가상) 값'입니다. 실제 자료로 바꿔서 쓰세요.

1) 비교유량_양식.csv  (예전 '기준유량' 열 이름도 그대로 읽힘)
   - 세션: 누적 DB에 등록된 세션 이름
   - 사용한_dis: (선택) 특정 .dis로 등록된 것만. 비우면 같은 세션 전체
   - 비교유량: 숫자 (예: 같은 시간 스마트 계측 유량)
   - 단위/출처/메모: 자유 입력

2) 외부시계열_양식.csv  (가장 단순한 형태: 시각, 값)

3) 예시_가상_FEWP형식.csv
   - 보고서(플랫폼 DB 표준)에 나온 열 이름(SML_RVR_CD 소하천코드, OBSR_DT 계측 일시 14자리, WAL 수위, TOT_DISCHA 유량)을
     흉내 낸 '가상' 예시입니다. 실제 FEWP 내려받기 파일의 열 이름은 다를 수 있습니다.
   - 프로그램에서 불러올 때 시각 열과 값 열을 직접 고르므로 열 이름이 달라도 됩니다.

※ 외부 자료는 불러올 때 '시간 기준(UTC+9/UTC)'과 '소하천코드'를 꼭 지정하세요.

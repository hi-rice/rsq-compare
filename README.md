# RSQ 회차 비교 도구 (시제품 v0.4.1)

SonTek RSQ에서 내보낸 계측 파일(.dis / .sum / .vel / .snr)을 폴더째 읽어서
**회차별 결과를 표·그래프로 비교하고 엑셀/PNG로 저장**하는 Windows용 작은 프로그램이야.

- RSQ의 유량 계산을 다시 하지 않아. 유량·폭·면적·평균 속력은 **DIS에 기록된 RSQ 결과**를 그대로 써.
- 원본 파일은 읽기만 하고 절대 수정하지 않아. 결과는 선택한 위치에 **새 폴더**로 저장돼.
- 설치가 끝나면 인터넷 없이 동작해(외부 서버·유료 API·AI API 사용 없음).

---

## 1. 설치 (처음 1회)

1. **Python 3.12** 설치 (python.org 설치 프로그램 사용 시 *Add python.exe to PATH* 체크 권장)
2. 이 폴더(`rsq_compare`)를 원하는 위치에 압축 해제
3. `setup.bat` 더블클릭 → `.venv` 폴더(가상환경)가 생기고 필요한 라이브러리가 설치됨
   - 이 단계만 인터넷이 필요해.

### 인터넷이 안 되는 PC에 설치하려면
인터넷 되는 PC(같은 Windows · Python 3.12)에서:
```
py -3.12 -m pip download -r requirements.txt -d wheels
```
만들어진 `wheels` 폴더를 이 폴더 안에 복사한 뒤 `setup.bat`을 실행하면 오프라인으로 설치돼.

## 2. 실행

- `run.bat` 더블클릭 (검은 창이 같이 뜨는 건 정상이야. 오류 메시지 확인용)
- 또는 명령 프롬프트: `.venv\Scripts\python.exe run_app.py "D:\자료\test"` (폴더를 바로 열기)

## 3. 사용 순서

| 순서 | 위치 | 할 일 |
|---|---|---|
| ① | 상단 `데이터 폴더 선택` | 압축을 푼 RSQ 내보내기 폴더 선택 (하위 폴더까지 탐색) |
| ② | 상단 `세션` | 세션이 여러 개면 골라. 세션 = `.dis` 파일 이름(예: `test_20261029_105656`) |
| ②-1 | 두 번째 줄 `DIS 파일` | 요약 결과를 읽을 .dis를 골라. RSQ에서 다시 내보낸 `<세션>_아무이름.dis`가 같은 폴더에 있으면 자동으로 후보에 들어가고, `다른 .dis 파일 선택…`으로 다른 위치의 파일도 고를 수 있어 |
| ③ | 왼쪽 회차 목록 | ☑ 체크 = 비교통계에 포함 / 항목 클릭 = 상세자료 탭에서 보기 |
| ④ | 오른쪽 탭 | 요약표 · 비교 그래프 · 상세자료 · 점검내역 확인 |
| ⑤ | 상단 `결과 저장` | 저장 위치 선택 → 그 안에 `<세션>_비교결과_<날짜시각>` 폴더 생성 |

### 탭 설명
- **요약표**: 회차(원래 T번호), 측정 파일명, 시작 Edge, 시작 시각(원문)과 시간 기준, 소요시간, 폭·면적·평균 속력·총유량(DIS), 상세 파일 존재/행 수, 요약 결과 존재 여부. 아래에는 DIS 설정·전체 결과 원문.
- **비교 그래프**: 회차별 총유량 막대그래프(선택 회차 = 파란색) + *선택 회차 단순 비교통계*(산술평균, 표본표준편차, 평균 대비 편차율).
  참고로 **[RSQ 방식] 모표준편차(n으로 나눔)·COV**도 같이 보여줘. RSQ 요약 패널의 '표준편차'·'COV'와 같은 계산이야
  (test 자료 8개 회차에서 RSQ 화면 1.164 / 0.399와 일치 확인). 표본표준편차(n−1)는 같은 회차라도 값이 더 커.
- **상세자료**: 회차의 `.sum` 원문 표, 샘플 번호별 수심·평균 속력 그래프, (추가 기능) `.vel` 셀 속도 분포.
  `구간` 상자에서 전체 / 시작 Edge / 횡단 섹션 / 마침 Edge를 골라 볼 수 있어(아래 '구간 정보' 참고).
- **점검내역**: 읽기 실패, 파일 누락, 출처 간 불일치, 시간 표기 차이 같은 확인 필요 사항 + `.dis` vs `.rsqmb` 출처 비교(참고).

### 저장 결과
```
<세션>_비교결과_YYYYMMDD_HHMMSS/
 ├ <세션>_회차비교.xlsx
 │   ├ 처리정보          : 프로그램 버전, 원본 폴더, 원본 파일 목록(크기·수정시각·SHA-256), 처리 조건
 │   ├ 회차요약
 │   ├ 비교통계_선택회차
 │   ├ 점검내역
 │   ├ DIS_설정및결과    : .dis 설정·전체 결과 원문
 │   ├ 출처비교_참고     : .dis vs .rsqmb Summary.json (.rsqmb가 있을 때)
 │   └ sum_T01 ...       : 회차별 .sum 원문
 └ 그래프/
     ├ 01_회차별_총유량_DIS.png
     ├ Txx_sum_수심_평균속력.png
     └ Txx_vel_셀속도분포.png   (상단 체크박스로 끌 수 있음)
```
- 숫자는 원본 정밀도 그대로 저장되고, 화면에서만 소수 4자리로 반올림해서 보여줘(셀에 마우스를 올리면 원본 값).
- `=`, `+`, `-`, `@`로 시작하는 글자는 엑셀이 수식으로 실행하지 않게 문자열로 저장돼.

## 3-1. ② 누적·비교 탭 — 현장 측정을 쌓아서 지점·수위·외부 자료와 함께 비교 (v0.4)

```
현장 RS5 측정 폴더 ─[📥 폴더에서 새 측정 가져오기]→ 누적 DB(파일 1개)
   소하천 목록(220개소 등) ─[소하천 목록 불러오기]→ 소하천코드만 있으면 소하천명·계측기·가까운 AWS 자동 표시
   FEWP 수위·유량, AWS 강우 ─[외부 자료 불러오기]→ 같은 소하천 세션의 회차 시간창에 연결
```

### 처음 한 번
1. `소하천 목록 불러오기(220개소 등)` → `220개소_…_AWS_특성정보포함.xlsx` 선택
   - **필요한 20개 열만** DB에 저장해(소하천명, 위치, 계측기, AWS 등). 서비스 Key·IP·RTSP·연락처 열은 읽지도 저장하지도 않아.

### 측정할 때 (RSQ에서) 해두면 자동으로 들어오는 것
| RSQ에서 입력 | 프로그램에서 |
|---|---|
| Site Information의 **Station Number에 소하천코드(11자리)** | 소하천코드 자동 연결 (출처: "RSQ 기록(Station Number)") |
| Edge 설정의 **Gauge Height(시작·끝 수위)와 관측 시각** (매뉴얼 82·96쪽) | 회차별 수위 자동 (출처: "RSQ 기록") |
| RS5 GPS(있는 장비) | .sum 위도·경도로 가장 가까운 소하천 **제안**(자동 확정은 안 함) |

### 기록이 없으면 직접 입력 (노란 칸 더블클릭)
| 정보 | 위치 | 규칙 |
|---|---|---|
| 소하천코드 | 세션 표 `소하천코드` | 숫자 11자리만 저장. 목록에 없으면 알려줌 |
| 측정자, 메모·날씨 | 세션 표 | 자유 입력 |
| 수위 | `지점·수위` 탭 → `직접 입력 수위` | **RSQ 기록이 있으면 RSQ 값 사용**, 없으면 직접 입력값. 둘 다 있고 다르면 '불일치' 표시. RSQ 값이 0이면 '미입력일 수 있음' 점검 |
| 비교 유량 | 세션 표 `비교 유량` (또는 `templates/비교유량_양식.csv`) | 예: 같은 시간 스마트 계측 유량. 차이만 계산, 판정 없음 |

### 외부 자료 (FEWP 수위·유량, AWS 강우 등)
- `외부 자료 불러오기` → 파일 선택 → **시각 열, 값 열(여러 개), 자료 종류, 단위, 시간 기준, 소하천코드**를 고르는 창이 떠.
  - 파일 형식이 정해져 있지 않아도 돼. 시각은 `2026-10-29 10:40`, 엑셀 날짜, **14자리 `20261029104000`**(플랫폼 OBSR_DT 형식) 등을 읽어.
  - 파일 안에 소하천코드만 들어 있는 열(예: `SML_RVR_CD`)이 있으면 **코드를 자동으로 골라 둬.** 여러 코드가 섞여 있으면 경고해.
- **소하천코드를 지정한 자료는 같은 코드의 세션에만 연결**돼(다른 하천 자료가 섞이지 않음). 코드가 없으면 연결할 측정을 직접 지정해야 해. 기존 미지정 자료도 '연결 대상 지정' 버튼으로 지정해.
- 회차 시간창(DIS 시작~시작+소요시간) 안의 값만 요약. **보간 없음.** FEWP처럼 2분 간격이면 `앞뒤 여유(분)`을 1~2분으로 줘 봐.
- 자료 종류가 **유량**이고 단위가 RS5와 같으면(`m³/s` = `m ³/s` = `CMS`) **RS5 회차 Total Q − 외부 평균**과 차이율을 보여줘. 단위가 다르면 계산하지 않아.
- **강우**는 구간 강우량·누적 강우량·강우강도를 구분해. 종류·단위·기록 간격을 확인하기 전에는 합산하지 않아. 구간값은 구간 끝 시각 기준이야. 경계 자료와 전체 구간이 연속이고 결측·초기화가 없을 때만 시간창 강우량을 표시해. 강우강도는 합산하지 않아.

### 그 밖에
- `💾 비교 결과 저장` → 엑셀(세션비교·회차전체·비교유량·**회차별_수위·측정지점_정보**·외부자료·점검내역) + 그래프
- 예전 DB는 처음 열 때 `.before-v4.bak` 전체 백업을 남기고 이관해. 기존 등록·입력은 보존해. 이전 버전에 없던 상세파일 해시는 복구할 수 없어서 관계 확인이 필요할 수 있어.
- 자동화: `가져오기.bat`의 `DATA`, `DB` 두 줄만 바꾸면 더블클릭 한 번으로 등록. 작업 스케줄러에 `가져오기.bat auto`로 등록 가능.
  명령줄: `python -m rsq_compare.cli_db --help` (sites / import / ref / ext / list / export)

### 시간 기준 주의
시간대가 없는 외부 시각의 기준은 불러올 때 **직접 골라야** 해. DIS도 원문 시간대를 우선하고, 없는 경우에만 열 머리글의 기준을 적용해.
원문에 Z나 +09:00이 있으면 그 시간대를 우선 사용해. 시간대가 없는 시각에만 사용자가 고른 기준을 적용하고 UTC로 비교해. 화면과 저장 결과에 원문·적용 기준·UTC 시각을 남겨. 이전 버전에서 이미 버린 시간대는 복구할 수 없으니 원본을 다시 불러와야 해.

## 4-1. 알아두면 좋은 RSQ 동작 (test 자료로 확인)

- **RSQ는 요약 패널(Ctrl+S)에서 체크된 회차만 .dis에 넣어.** 전체 Total Q도 그 회차들의 평균이야.
  - 원본 .dis(T07 빠짐): 7개 평균 = **3.332**
  - T07을 체크하고 `내보내기 > 유량 요약`으로 다시 만든 .dis: 8개 평균 = **2.9181** (RSQ 화면·PDF와 같은 값)
- 그래서 어떤 회차가 "요약 결과 없음"으로 나오면, RSQ에서 그 회차를 체크하고 `내보내기 > 유량 요약`으로 새 .dis를 만든 뒤
  이 프로그램 상단 `DIS 파일`에서 고르면 돼. (RSQ를 닫을 때 저장 여부를 물으면 원본 보존을 위해 '아니오')
- 점검내역의 '회차 포함/제외' 항목이 "DIS 전체 Total Q = 들어간 회차들의 평균"인지 자동으로 확인해 줘.

## 6. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| `setup.bat`에서 실패 | Python 3.12 설치 여부, 인터넷 연결(또는 `wheels` 폴더) |

## 7. 알려진 한계 (v0.4.1)
- 구간 정보는 `.rsqmb`가 있어야 표시돼(.sum/.vel만 있으면 전체 기록만 표시).
- `.vel` 셀 위치의 기준면은 매뉴얼로 확정하지 못해 "셀 위치(원문 값)"로 표시
  (원시 CellStart + Transducer Depth 0.05 m = .vel 셀 시작 관계는 관찰됨 → 수면 기준일 가능성).
- `.sum`/`.snr` 시각은 원시 로그의 UTC 시각과 같음(525/525). 그래도 자동 변환은 하지 않음.
- `.snr`은 행 수·샘플 번호 점검에만 쓰고 그래프·엑셀 상세 시트는 만들지 않음.
- `.rsqmb`는 내부 Summary.json / DataSessionProperties.json만 참고로 읽음(원시 바이너리 미해석).
- RSQ 화면의 노란색 행 의미, V1~V4·정상유속 의미는 문서 확인 전이라 사용하지 않음.

## 시간·외부 자료·강우 수정 검증

가상 자료 회귀 검증: `.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v`
실제 자료 검증과 구분한 결과·제약은 [개발 안내](DEVELOPMENT.md)를 참고하세요.
CLI 외부자료 등록에는 `--site 소하천코드` 또는 `--session-id 등록ID`가 필요합니다.
강우는 `--rain-type "구간 강우량"` 또는 `"누적 강우량"`, `--rain-interval 분`을 지정합니다.
단위가 mm이고 경계와 연속성을 확인할 수 있을 때만 집계합니다.
`--rain-type "강우강도" --unit mm/h`는 강도로 표시하며 강우량으로 합산하지 않습니다.

## 중복·변경 감지와 코드 확인

- 입력 DIS·상세파일(다른 좌표계 포함)·rsqmb의 해시를 저장해. 파일·폴더 이름만 바꾼 같은 내용은 중복 등록하지 않아.
- 재처리본은 이전 등록과 연결해 보존해. 새 버전이 기존 버전을 자동으로 대체하지 않으며, 비교할 버전은 하나만 체크해.
- 같은 측정인지 불확실하면 `[확인 필요]`로 표시해. **측정 관계 확인**에서 별도 측정인지 이전 등록의 재처리본인지 직접 지정해.
- **측정 이력** 탭에서 이전 등록·변경 파일·확인 상태를 봐. 확인 전 자료와 같은 측정의 여러 버전을 함께 비교·저장하려 하면 안내하고 멈춰.
- 회차 체크와 비교 체크, 메모·수위·비교 유량 입력을 보존해. 새 버전에는 대응 회차의 선택·입력을 이어 주며 이전 행은 지우지 않아.
- 소하천 목록은 모든 행을 저장해. **코드 확인**에서 완전 중복과 정보 충돌을 구분하고, **코드 행 선택**으로 사용할 행을 확인해.
- 충돌 코드는 확인 전까지 자동 지점 정보·GPS 제안·코드 기준 외부자료 연결에 사용하지 않아. 새 충돌 정보가 들어오면 다시 확인해야 해.
- 관리코드는 문자열로 보존해. Excel에서 11자리 0 표시 형식이 명시된 코드도 선행 0을 유지해. 이미 사라진 숫자를 임의로 채우지는 않아.

CLI 확인:

```bash
python -m rsq_compare.cli_db review --db private.db --id 12 --previous 4
# 별도 측정으로 확인하려면 --previous 생략
python -m rsq_compare.cli_db catalog-review --db private.db
python -m rsq_compare.cli_db catalog-review --db private.db --choose 7
```

검증 내역과 미실행 항목은 [개발 안내](DEVELOPMENT.md)를 참고해.
